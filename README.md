# 🍏 NutriAprova

Plataforma SaaS inteligente para nutricionistas e pacientes, integrando geração de planos alimentares via IA com uma experiência de usuário premium.

## 🚀 Tecnologias Utilizadas
* **Front-end:** React, Tailwind CSS, Vite
* **Back-end & Banco de Dados:** Supabase (PostgreSQL, Auth, RLS)
* **Inteligência Artificial:** n8n (Integração e Automação)

## 📋 Funcionalidades Principais
* **Dashboard do Paciente:** Visualização de perfil, paywall integrado e acompanhamento de métricas.
* **Geração de Dieta com IA:** Motor inteligente que cria cardápios baseados no peso, altura e restrições do cliente.
* **Comunidade:** Espaço interativo para nutricionistas e pacientes compartilharem receitas e dicas.
* **Controle de Acesso (RBAC):** Permissões estritas separando Pacientes, Nutricionistas e Administradores.
